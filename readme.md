# Unit Converter

A simple and responsive unit conversion web application built with PHP, HTML, CSS, and JavaScript.

## Project Overview

This project allows users to convert values between different units in three categories:

- Length
- Weight
- Temperature

The conversion logic is handled in PHP, while JavaScript is used to improve the user interface and update unit options dynamically.

## Features

- Convert values across multiple unit categories
- Support length, weight, and temperature conversion
- Dynamic unit list based on the selected category
- Input validation for empty or invalid values
- Clear result display
- Responsive layout for desktop and mobile devices
- No database or external dependencies required

## Technologies

- PHP
- HTML5
- CSS3
- JavaScript

## How to Run

1. Put the project folder inside your Laragon `www` directory.
2. Start Apache in Laragon.
3. Open the app in your browser:

```text
http://localhost/unit_converter
```
